## Verified source facts (use these; re-verify before writing)

- **Module:** `github.com/Miniature-Pug/perch`. Go directive `1.25.0`, toolchain `go1.26.2`. Charm locked: bubbletea v1.3.10, bubbles v1.0.0, lipgloss v1.1.0. tmux pin `3.6` (`.tool-versions`, read by doctor).
- **CLI:** `perch` (bootstrap frame+TUI), `perch <path>`, `perch --sidebar`, `perch setup [--replace]`, `perch attach <query>`, `perch resurrect`, `perch status set <working|waiting|done>`, `perch doctor`, `perch version`. (`perch debug discover|tmux` exist but are hidden — do NOT advertise in the README; mention in ARCHITECTURE as debug aids only.)
- **TUI keys:** `/` filter · `esc` clear filter · `↵` open · `n` new · `q`/`ctrl+c` quit · `d` remove · `x` kill · `w` worktree · `z`/`Z` screen mode fwd/back · `c` collapse sidebar · `?` help · `:` command bar. Up/Down owned by bubbles/list.
- **`:` verbs:** `q`/`quit`, `new`, `attach <query>`, `proj`/`project <name>`, `setup [--replace]`, `doctor`, `resurrect`, `help`/`h`/`?`. Unknown → toast; empty → silent cancel. **`:resurrect` refuses inside the frame** (points the user to startup/shell).
- **Focus model (FD, locked option 1):** default tmux socket; once focus is in the agent's main pane, return to the sidebar with the tmux **`prefix ←/→`** (or `prefix o`). The sidebar stays visible; switching sessions is in-perch (select + ↵ swaps the agent into the main pane).
- **Frame model:** `perch` bootstraps a `perch` tmux session = a sidebar pane (the TUI, run as `perch --sidebar`) + a main pane. Each agent runs in its OWN detached tmux session. Selecting a session **swap-pane**s the agent into the main slot (no re-resume). One disposable placeholder pane exists for the frame's lifetime. `q` swaps the displayed agent **home before** killing the frame (so agents survive). If `frame.Ensure` fails, perch falls back to the direct two-pane TUI.
- **State:** base `$XDG_STATE_HOME/perch/` (fallback `~/.local/state/perch/`). `state.json` = `mappings` (session→worktree choice) + `projects` (frecency rank/last_accessed). `windows/<k>.json` = one file per live tmux window (concurrent-safe). Both read via 16 MiB-capped `readLimited`.
- **Config:** global `$XDG_CONFIG_HOME/perch/config.toml` (default `~/.config/perch/config.toml`): `roots []string`, `sort_order []string`, `blacklist []string`, `refresh_ms *int`, `worktree_dir *string`, `[default_session].agent/startup_command`, `[theme].accent`, `[agents].<name>` (absolute binary path — **global-only security boundary**). Project `.perch.toml` (walked up): `base_branch`, `worktree_dir` (relative-only), `agent`, `post_create []string`, `pre_remove []string`, `pre_merge []string`, `[files].copy/symlink`, `[[wildcard]]` (pattern+agent). **Project config has NO agents map** — it cannot influence binary resolution.
- **Trust (V1, M10):** opening a repo whose `.perch.toml` defines shell hooks (`post_create`/`pre_remove`/`pre_merge`) prompts a trust modal — `(a)` trust always / `(o)` once / `(d)` deny — keyed on resolved config path + content hash, stored mode 0600 in `<base>/trust.json`, TOCTOU-closed by re-hashing before exec.
- **Status pipeline:** agent hook → `perch status set <state>` → writes `@perch_pane_status` tmux option on the agent pane → TUI `statusPoll` (every `refresh_ms`) reads it → list glyph (🤖 working / 💬 waiting / ✓ done / ● live / ○ idle). Focusing an agent (swap-in) auto-clears its badge.
- **Resurrect:** `perch resurrect` (and the bootstrap auto-offer on a detected restart) runs `Reconcile`: per recorded window → KEEP (pane live + boot match) / PRUNE (pane gone, same boot, home session alive) / RESTORE (boot mismatch or cold server → re-launch the agent). The bootstrap offer is tty-gated (default N) and runs pre-frame.
- **Testing seam (§20.1):** all shell-outs go through `proc.Runner`; unit tests use `FakeRunner` (assert `.Calls`, never spawn); integration tests (`//go:build integration`) use a PRIVATE tmux socket. Coverage ≥80% all packages except `internal/tui` (exempt). Hermetic vendored build (`-mod=vendor`).
- **Make targets:** build, install, run, test, test-integration, test-all, coverage, lint (golangci-lint v2.11.4), fmt, vet, tidy, vendor, verify, vulncheck (govulncheck v1.3.0), doctor, cross, clean.
